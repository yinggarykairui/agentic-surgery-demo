# Agentic AI for endoscopic surgery: demo video

Gary Ying, AUTOLab, 2026-10-20. Three-minute captioned demo.

**Video:** [agentic_demo.mp4](https://github.com/yinggarykairui/agentic-surgery-demo/raw/main/agentic_demo.mp4) (3.4 MB, 170 s)

Segments:
1. Claude Opus 5.5 and GPT-5.5 exploring a public PitVis pituitary video with look/zoom tools and answering a surgical question.
2. Claude Opus 5.5 and GPT-6 Astra steering an instrument to a target on deformable tissue in NVIDIA Newton.
3. GPT-6 Astra and Claude Opus 5.5 doing the same in RoboSimStudio with a Panda-held instrument and an endoscope camera.

All renders are CPU, no path tracing. Contains only public PitVis data and simulation renders; no UCSF footage.
